How to get started

  • 1 Go to console.groq.com and create a free account — no credit card needed.
  • 2 In the left sidebar click API Keys, then click Create API Key.
  • 3 Copy the key — it starts with gsk_. You only see it once, so copy it now.
  • 4 Click the chat bubble at the bottom-right, paste your key, and start chatting.
